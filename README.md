
Credit Card Customer Churn Prediction

A Machine Learning project that predicts whether a credit card customer is likely to churn based on customer demographics, account information, transaction behavior, and usage patterns.

The project covers the complete machine learning workflow, from data preprocessing and exploratory data analysis to model training, evaluation, and churn prediction.

🚀 Features
Exploratory Data Analysis (EDA)
Data cleaning and preprocessing
Feature selection and engineering
Categorical variable encoding
Machine learning classification
Model performance evaluation
Customer churn prediction
Identification of factors associated with customer attrition
🛠️ Tech Stack

Python | Pandas | NumPy | Scikit-learn | Matplotlib | Seaborn | Jupyter Notebook
